# ShortNews — Агрегатор новин з AI-сумаризацією

Проєкт створено як курсову роботу. Додаток дозволяє переглядати свіжі новини за категоріями та генерувати короткий переказ (summary) за допомогою штучного інтелекту Google Gemini.

## Технології
* **Frontend:** React, Vite, Tailwind CSS.
* **Іконки:** Lucide-React.
* **API Новин:** NewsAPI.org.
* **AI:** Google Gemini API (модель gemini-2.5-flash).

## Як запустити проєкт
1. Встановіть [Node.js](https://nodejs.org/).
2. Розпакуйте архів та відкрийте термінал у папці проєкту.
3. Виконайте команду для встановлення бібліотек:
   ```bash
   npm install
